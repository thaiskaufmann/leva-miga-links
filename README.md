# Leva, miga! — links por post

Página de achadinhos do Instagram **Leva, miga!**: cada publicação tem seus links de afiliada.

- `index.html` — a página pública e o painel (`/admin`), num arquivo só.
- `_redirects` — faz o endereço `/admin` abrir o painel no Netlify.
- `setup.sql` — configuração do banco no Supabase (já foi rodada; guardado só como referência).

Posts, produtos e perfil ficam no Supabase e são editados pelo painel, sem mexer nestes arquivos.
